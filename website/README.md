# WebAI.js website

Standalone Next.js copy of the landing page in `../hubters-webai-frontend`. The page, landing sections, supporting components, Tailwind configuration, and public assets were copied from that project. This app has no authentication or database.

```bash
npm install
npm run dev
```

Open the URL printed by Next.js. Links to pages outside the landing page point to the existing WebAI.js site. The original landing page's example code and copy are preserved; the library's [README](../README.md) has the current v4 API example.
